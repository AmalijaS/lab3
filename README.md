## Содержимое папки `examples`

В папке `examples` находятся следующие файлы:

- `example1_gr12a_SakalouskajaAmalija.c` – создание базы данных, таблицы, вставка и выборка данных (callback).
- `example2_gr12a_SakalouskajaAmalija.c` – параметризованные запросы с использованием `sqlite3_prepare_v2` и `sqlite3_bind_*`.
- `example3_gr12a_SakalouskajaAmalija.c` – вставка и извлечение BLOB (изображений) в SQLite.
- `example4_gr12a_SakalouskajaAmalija.c` – демонстрация autocommit и явных транзакций (`BEGIN` / `COMMIT` / `ROLLBACK`).
- `example5_gr12a_SakalouskajaAmalija.c` – получение метаданных: список таблиц, структура колонок, PRAGMA.
- `EXAMPLES.md` – подробное описание каждого примера (markdown).

## Компиляция и запуск примеров

### Требования
- Компилятор C (gcc, clang и т.д.)
- Установленная библиотека SQLite3 (разработка: заголовочные файлы и библиотека)

### Установка SQLite3 (если ещё не установлена)
- **macOS (Homebrew):** `brew install sqlite3`

### Компиляция
Перейдите в папку `examples` и выполните:
```bash
gcc -o example1 example1_gr12a_SakalouskajaAmalija.c -lsqlite3
gcc -o example2 example2_gr12a_SakalouskajaAmalija.c -lsqlite3
# и так далее для каждого примера
```

### Запуск
```bash
./example1
./example2
...
./example5
```

**Примечание:** Примеры 2–5 предполагают, что база данных `test.db` уже содержит таблицу `COMPANY` (создаётся при первом запуске `example1`). Для корректной работы запускайте их после `example1`.
